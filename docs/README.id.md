Di sini saya membagikan 140 gambar dan 11 video dari arsip pribadi di Desktop: kenangan masa kecil dan keluarga, momen bersama teman, foto seputar promosi dan apresiasi terhadap buku saya, serta potret dan suntingan kreatif. Senang bisa berbagi sisi yang lebih pribadi dari dunia kreatif saya.
